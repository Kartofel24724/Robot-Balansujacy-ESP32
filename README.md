## Robot balansujący działający na ESP32

## lista części:

Elektronika:

- Moduł ESP32 DevKit 30pin
- czujnik IMU MPU6050
- 2 silniki krokowe NEMA17 1.5A
- 2 sterowniki DRV8825
- 3 kondensatory elektrolityczne 100uF
- rezystor 1kΩ
- najbardziej standardowa dioda LED jak się tylko da
- stabilizator napięcia L7805
- 3 ogniwa litowo-jonowe 18650 + układ BMS
- złącze ARK 2.54mm
- para złącz XT60/XT30
- kable i koszyk na akumulatory

Reszta części:

- obudowa i koła wydrukowane w 3D (PLA, PETG, TPU)
- śruby, nakrętki i podkładki M2 i M3
